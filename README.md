# ウイスキー お好みカルテ / Whisky Tasting Profile

ご来店いただいたお客様の好みを記録する、店舗用のデジタルカルテです。
紙のカルテ（`ウイスキー お好みカルテ` Word 版）の全12セクションをそのままアプリ化しています。

- **ファイルは `index.html` の1つだけ**。インストール不要・通信不要で、ダブルクリックすれば開きます。
- タブレット（iPad など）に入れて、カウンターでお客様に直接記入していただけます。
- 記入内容から **フレーバープロファイル（レーダー）** と **おすすめの方向性** が自動で組み立てられます。
- **A4のカルテとして印刷**できます。白紙のカルテ（手書き用）も同じレイアウトで印刷できます。

## 使い方

1. `index.html` をタブレットや店舗のPCにコピーして開く（ブラウザは Safari / Chrome / Edge）。
2. 右上の「店舗名」を一度入力すると、以降ずっと保存され、印刷したカルテにも入ります。
3. 左の 01〜12 を記入 → 右の「このカルテを保存」。カルテNo.は自動採番（0001, 0002 …）。
4. 「お客様一覧」タブから、過去のお客様を検索・再表示・追記できます。
5. iPad なら Safari の「共有 → ホーム画面に追加」でアプリのように起動できます。

### 07 フレーバーホイール
外周をタップすると「08 好きな香味」に登録され、「09 フレーバープロファイル」の点数も自動で上がります。
点数は 09 の図の点を直接タップして手で調整もできます（「香味の選択から自動採点」で再計算）。

### 印刷
- **印刷** … 表示中のカルテを A4 2ページ（基本情報／フレーバー）で印刷します。PDF保存も同じ操作です。
- **白紙のカルテを印刷** … 手書き用のブランクカルテ。紙で受け付けて、あとから入力する運用にも使えます。

## データについて

- カルテはお使いの**端末のブラウザ内（localStorage）にのみ保存**されます。外部へは一切送信されません。
- お客様の個人情報を含みますので、端末の管理（画面ロック等）をお願いします。
- 端末の入れ替え・バックアップは「お客様一覧」下部から:
  - **JSONで書き出し** … 全データのバックアップ（読み込みで復元・統合できます）
  - **CSVで書き出し** … Excel / Googleスプレッドシートでの集計用
  - **JSONを読み込み** … 別端末の書き出しファイルを追加読み込み（No.が重複しないよう調整されます）
- ブラウザの「サイトデータを削除」を実行すると消えます。定期的な書き出しをおすすめします。

## 項目をお店に合わせて変える

`index.html` 内の先頭にある2つの定義を書き換えるだけで、選択肢を差し替えられます。

- `CATS` … フレーバーホイールの8カテゴリーと、その中の香味・色
- `GROUPS` … 樽の種類、産地、予算帯などのチェック項目
- `SCALE_SETS` … ピート／味わいのバランスの5段階スケール

例えば予算帯を変えるときは `budgetGlass` / `budgetBottle` の `items` を書き換えてください。
ホイール・レーダー・印刷・CSV のすべてに自動で反映されます。
