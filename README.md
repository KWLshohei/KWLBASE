# KWL 好み交換カード

関西ウイスキーラバーズ(KANSAI WHISKY LOVERS)の、**名刺がわりの好み交換カード**を作る Web アプリです。

イベントや例会では毎回「何がお好きですか?」「苦手なものはありますか?」を一人ずつ聞くところから会話が始まります。
その最初のやりとりを 1 枚の画像に置き換えて、**見せ合った瞬間に好みが伝わる**ようにするのがこのアプリの目的です。

## できること

- 好きな味・苦手な味を、12 種類のフレーバーから選ぶ(タップで 好き → 苦手 → 解除 と切り替え)
- ニックネーム / ウイスキー歴 / 好きな飲み方 / いま推してる一本 / ひとこと を入力
- 好みに合わせた背景アートを AI で生成し、カード画像(1080 × 1350 PNG)に合成
- PNG で保存、またはスマホの共有シートからそのまま送る
- 入力内容はブラウザに保存されるので、次のイベントでも作り直せる

## セットアップ

```bash
npm install
cp .env.example .env.local   # OPENAI_API_KEY を設定(任意)
npm run dev
```

http://localhost:3000 を開きます。

### 環境変数

| 変数 | 必須 | 説明 |
| --- | --- | --- |
| `OPENAI_API_KEY` | 任意 | 背景アート生成に使う OpenAI の API キー。サーバー側でのみ読み、ブラウザには渡しません。 |
| `OPENAI_IMAGE_MODEL` | 任意 | 画像生成モデル。既定は `gpt-image-1`。 |

`OPENAI_API_KEY` が未設定でも、あるいは生成に失敗しても、アプリは止まりません。
その場合は**選んだ好きな味の色から作るグラデーション背景**にフォールバックし、カードは問題なく作れます。

## 仕組み

AI が作るのは**背景アートだけ**です。名前やフレーバーなどの文字は、生成画像の上に Canvas で描いています。
画像生成モデルは日本語の文字を正しく描けないため、この分担にすることで「絵は好みに沿っていて、文字は必ず読める」カードになります。

```
入力(好き / 苦手)
  ├─ src/lib/prompt.ts    → 好みを英語の情景に変換してプロンプトを組む
  │    └─ /api/artwork     → OpenAI 画像生成 API(サーバー側・キーは非公開)
  └─ src/lib/cardRenderer.ts → 背景 + 文字を Canvas で 1080×1350 に合成
```

| ファイル | 役割 |
| --- | --- |
| `src/lib/taste.ts` | フレーバー・飲み方・ウイスキー歴の語彙と入力の正規化 |
| `src/lib/prompt.ts` | 背景アート用プロンプトの組み立て |
| `src/lib/cardRenderer.ts` | カード画像の描画(レイアウト・折り返し・配色) |
| `src/app/api/artwork/route.ts` | 画像生成 API の呼び出し口 |
| `src/components/CardStudio.tsx` | 入力フォームとプレビュー |

## カスタマイズ

- **フレーバーの語彙を変える**: `src/lib/taste.ts` の `FLAVORS` を編集します。`color` はカード上のチップ色とフォールバック背景に、`art` は画像生成プロンプトに使われます。
- **カードの見た目を変える**: `src/lib/cardRenderer.ts` の `layoutBody` / `drawFrame` を編集します。カードの寸法は `CARD_W` / `CARD_H` です。

## デプロイ

Next.js アプリなので Vercel などにそのまま載せられます。`OPENAI_API_KEY` を環境変数に設定してください。

`/api/artwork` には 1 インスタンスあたり 15 分で 15 回の簡易レート制限が入っています。
プロセスのメモリ上で数えているため、複数インスタンスに分かれる環境では厳密ではありません。
広く公開する場合は、API 課金額の上限設定とあわせて見直してください。
