# KWLBASE — ウイスキー蒸留所 & ボトル記録アプリ

世界中のウイスキー蒸留所を地図から辿り、**気になった蒸留所をクリックして自分の飲んだボトルを登録**していく、
ウイスキー好きのための記録アプリです。

<!-- スクリーンショットはリポジトリには含めていません。`npm run dev` で確認できます。 -->

## できること

| 機能 | 内容 |
| --- | --- |
| 世界地図 | 108 蒸留所（22 の国・地域）をピン表示。ドラッグで移動、ホイール／ピンチで拡大縮小。拡大すると高精細な地形と蒸留所名を表示 |
| 利用登録 / ログイン | ニックネーム・メールアドレス・パスワードで登録。ログイン中のユーザーの記録だけが表示されます |
| ボトル登録 | 蒸留所をクリック →「ボトルを登録」。熟成年数・ヴィンテージ・度数・樽・購入価格・状態（開栓中／未開栓／空き瓶／欲しい）・評価（★0.5 刻み）・テイスティングノートを記録 |
| テイスティング評価 | スモーキー / 甘み / フルーティ / スパイシー / コク / 華やかさ の 6 軸を 0〜5 で入力し、レーダーチャートで表示 |
| マイコレクション | 登録ボトル数・蒸留所数・国数・訪問済み数・平均評価の集計、**好みの傾向**（全ボトルの平均フレーバー）、検索・国／状態での絞り込み・並べ替え |
| 訪問記録 | 実際に訪れた蒸留所を「訪問済み」としてチェック |
| 蒸留所の追加 | 一覧にない蒸留所を、緯度経度を指定して自分の地図に追加 |
| クイックジャンプ | スコットランド・アイルランド・日本・アメリカ・欧州・アジア大洋州へワンタップで移動 |

地図上のピンは、**自分がボトルを登録した蒸留所ほど明るく光る**ようになっています。飲むほど地図が育つ設計です。

## 動かし方

```bash
npm install
npm run dev      # http://localhost:5173
```

```bash
npm run build    # dist/ に静的ファイルを出力
npm run preview  # ビルド結果の確認
```

出力は完全な静的サイトなので、GitHub Pages・Netlify・Vercel・S3 などにそのまま置けます。

## データの保存について

このアプリは**サーバーを持ちません**。アカウント情報・ボトル記録・追加した蒸留所は、すべて
ブラウザの `localStorage` に保存されます。

- 端末やブラウザが変わると記録は引き継がれません
- ブラウザのデータを削除すると記録も消えます
- パスワードはソルト付き SHA-256 ハッシュで保存していますが、あくまでローカル完結のデモ用認証です

複数端末で共有したり、仲間内で見せ合えるようにする場合は、`src/lib/storage.js` /
`src/lib/auth.js` / `src/lib/bottles.js` の 3 ファイルをサーバー API（Supabase・Firebase・
自前バックエンド等）に差し替える構成にしてあります。

## 構成

```
src/
├── App.jsx                     画面全体の状態管理とレイアウト
├── theme.js                    デザイントークン（色・角丸・フォント）
├── data/
│   ├── distilleries.js         蒸留所シードデータ + 地域プリセット
│   └── flavor.js               テイスティング6軸・カテゴリ・樽の種類
├── lib/
│   ├── storage.js              localStorage 永続化（差し替えポイント）
│   ├── auth.js                 利用登録・ログイン
│   ├── bottles.js              ボトルの正規化・CRUD・集計
│   └── useMedia.js             レスポンシブ判定
└── components/
    ├── WorldMap.jsx            d3-geo + TopoJSON の世界地図（パン/ズーム/ピンチ）
    ├── DistilleryPanel.jsx     蒸留所の詳細とボトル一覧
    ├── BottleForm.jsx          ボトル登録・編集フォーム
    ├── BottleCard.jsx          ボトルカード
    ├── CollectionView.jsx      マイコレクション（統計・絞り込み）
    ├── FlavorRadar.jsx         レーダーチャート（recharts を遅延読み込み）
    ├── AuthDialog.jsx          利用登録・ログイン
    ├── AddDistilleryDialog.jsx 蒸留所の追加
    └── ui.jsx                  ボタン・入力・モーダル等の共通部品
```

主な依存：React 18 / Vite 5 / d3-geo / topojson-client / world-atlas / recharts / lucide-react。

初期表示に不要な recharts と高精細地形（`countries-50m`）は動的 import で分割しており、
初回ロードは約 117 KB（gzip）です。

## 蒸留所データについて

`src/data/distilleries.js` に配列としてまとめています。1 行が 1 蒸留所です。

```js
["yamazaki", "Yamazaki", "山崎", "日本", "大阪", 1923, 34.8900, 135.6740, "シングルモルト"],
//  id        英名        和名     国      地域    創業年   緯度      経度      スタイル
```

追加・修正はこの配列に行を足すだけで地図と一覧に反映されます。
**緯度経度は地図表示用のおおよその値**で、公式の所在地とは数百 m 程度ずれることがあります。
アプリ内の「蒸留所を追加」から登録した分は、その端末のブラウザにのみ保存されます。
